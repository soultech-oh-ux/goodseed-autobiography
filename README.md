# GOODSEED — 자서전 쓰고 출판하기 8주 과정

8주 자서전 집필 및 출판 과정 홍보 페이지. 별도 빌드가 필요 없는 HTML 정적 사이트입니다.

## 파일 구성
- `index.html` — 모바일/PC 반응형 모집 랜딩페이지
- `poster.html` — A4 홍보 안내장 인쇄용 웹페이지
- `guide.pdf` — A4 홍보 안내장 PDF
- `guide.png` — A4 홍보 안내장 이미지
- `og-cover.png` — 링크 공유용 가로형 이미지
- `workbook.html` — 업로드된 자서전 워크북(질문·입력·DOCX/PDF 저장)
- `qr-professor.png` — 오경근 교수 소개 홈페이지 QR코드
- `qr-namecard.png` — 오경근 교수 디지털 명함 QR코드
- `qr-inquiry.png` — 카카오톡 상담 QR코드

## GitHub + Vercel 배포
1. GitHub에서 새 저장소(예: `goodseed-autobiography`)를 만듭니다.
2. 이 폴더 **안의 파일 전체**를 저장소 루트에 업로드하고 커밋합니다. (ZIP 자체를 업로드하면 사이트가 동작하지 않습니다.)
3. Vercel → **Add New → Project** → GitHub 저장소 Import.
4. Framework Preset은 **Other**, Root Directory는 `/`, Build Command는 **비움**, Output Directory도 **비움**으로 둡니다.
5. **Deploy**하면 `index.html`이 메인 페이지가 됩니다. `/workbook.html`은 워크북, `/poster.html`은 안내장입니다.

## 출판·모집 정보 확인사항
- 개강일, 교육장소가 주어지지 않아 `신청 시 별도 안내`라고 표기했습니다. 최종 공고 전에 확정 정보를 반영하세요.
- 수강 상담은 오경근 교수 홈페이지에서 확인되는 카카오톡 오픈채팅(`https://open.kakao.com/o/g8X6BQZh`)으로 연결했습니다. 실제 모집용 채널이 다르면 링크를 변경하세요.
- 비용은 **8회 × 10만 원 = 80만 원** + **출판 준비·제작 및 행정 패키지 20만 원** = **총 100만 원(부가세 포함)**으로 표시했습니다.
- 종이책과 전자책은 서로 다른 ISBN을 사용합니다. ISBN 번호 자체의 발급은 무료이며 출판 행정/제작 지원 패키지 비용과 구분해야 합니다.
- 교보문고 유통 및 판매 개시는 해당 서비스의 가입·심사·등록 절차를 완료한 뒤 가능합니다. '출판 추진'으로 표기했습니다.
- 참가비 전액 후원 문구는 주최자의 진술을 그대로 표기한 것이므로 집행 방식과 회계 처리, 부가세/출판 실무비용 처리 방식을 확인한 뒤 광고하세요.
- 워크북은 `localStorage`로 같은 브라우저의 입력 내용을 저장합니다. 다른 컴퓨터와 자동 동기화하지 않으므로 DOCX/PDF 파일로 자주 보관하세요.

## 8주차별 진행 내용 (홍보물 최신 수정본)
1. 자서전 기획 및 과거 이야기 쓰기
2. 현재의 나 쓰기
3. 미래의 나 쓰기
4. 원고 편집 1
5. 원고 편집 2 및 미래 그림 만들기
6. 원고 최종 교정 및 출판 준비 (6주차 미지정으로 제안한 구성)
7. 목차와 표지 만들기
8. 교보문고 출판 및 등록 실무

홍보물의 숫자 136문항은 전부 「인생 질문」으로 바꿨고, 실제 워크북의 질문·입력·저장 기능은 유지했습니다.
인쇄용 홍보물 및 웹페이지 맨 아래에 `ISBN 비용은 포함된 가격입니다.`라는 안내를 추가했습니다.

## 상담처·QR 최신 안내
홍보 홈페이지 및 PDF 하단 상담처는 윈바신갈지역아동센터 센터장, 전화 010-9990-1894로 표기합니다. 인쇄물의 두 QR은 각각 디지털 명함과 오경근 교수 홈페이지로 연결되며, 웹 주소도 인쇄물에 기재합니다. 웹사이트의 기존 카카오톡 상담 QR은 유지합니다.
